Why isn’t PoopLockWIFI.shortcut already in this folder?
================================================================================

Apple’s .shortcut files are created by the Shortcuts app (on iPhone or Mac), not by Xcode.
This repo ships the RECIPE (text) so anyone can build the same shortcut in ~2 minutes.

After YOU build it once:
  Shortcuts → ••• → Share → export → save as PoopLockWIFI.shortcut
  → add the file to the Xcode target (Copy Bundle Resources)
  → or upload to GitHub Raw / iCloud and set officialImportURL

See EXPORT-INSTRUCTIONS.txt for maintainer steps.
